# Manual ISPMAX

El contenido de este manual **no está en el código fuente**: vive en la base de datos del portal de administración y se genera desde allí.

Para cargarlo en un sistema nuevo, entra en `/admin/` y usa **Cargar contenido** con el archivo `.ispmax` (o `npm run content:import` desde `portal/`).
